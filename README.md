# Make the AI judge feel brave

make.fun entry for `make-the-ai-judge-feel-brave-20261121-0302`.

`main.py` (Python 3.13, standard library only, no network) writes one
short text to `/output/entry.txt`: a quiet night-kitchen scene — a kettle
gone still, rain finding the same slow path down the glass, a porch light
down the road staying lit, in no hurry. It shows rather than instructs:
no commands to the reader, no stock wellness phrases, one concrete image
that lingers after the last line.

Run it with:

```sh
python3 main.py
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`):
UTF-8, 261 characters.
